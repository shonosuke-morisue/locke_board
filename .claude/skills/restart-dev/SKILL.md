# 開発サーバーの再起動

このプロジェクトは ts-node-dev の中間コンパイルエラーを避けるため、修正後はサーバーを手動再起動する運用になっている（CLAUDE.md 参照）。このスキルはその手順を一括で行う。

## 手順

1. **ポートを解放する**（既存プロセスを停止）。プロセスが無くてもエラーにしない。
   ```bash
   kill $(lsof -ti:3001) 2>/dev/null; kill $(lsof -ti:5173) 2>/dev/null; true
   ```

2. **サーバーをバックグラウンド起動する**（`run_in_background: true` を指定して Bash で実行）。
   ```bash
   cd server && npm run dev
   ```

3. **クライアントをバックグラウンド起動する**（同じく `run_in_background: true`）。
   ```bash
   cd client && npm run dev
   ```

4. 数秒待ってから各プロセスの出力を確認し、サーバーが `3001`、クライアントが `5173` で待ち受けていること（起動ログ／エラーの有無）を報告する。エラーがあれば内容を提示する。

## 注意

- 手順2・3は長時間実行されるプロセスなので、必ずバックグラウンドで起動すること（前景で実行するとブロックする）。
- クライアント（Vite）はホットリロード対応なので通常は再起動不要だが、プロセスが落ちている場合のために起動する。すでに 5173 が生きているなら手順1で一旦落として上げ直す。
- 起動確認は `http://localhost:5173`。本番相当の確認が必要な場合は CLAUDE.md の本番手順を参照。
